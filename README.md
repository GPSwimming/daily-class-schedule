# 泳堂管家｜Codex 可編輯分享版

呢個資料夾包含完整 Web App 原始碼，可以直接交俾朋友，再由朋友喺自己嘅 Codex 開啟、修改及部署。

## 包含內容

- `dist/index.html`：網頁結構
- `dist/styles.css`：手機及桌面版樣式
- `dist/app.js`：全部功能及瀏覽器本機資料處理
- `dist/location-import.js`：泳班地點試算表首批資料、五欄驗證與匯入比對
- `tests/app-smoke.mjs`：基本完整性測試
- `serve.mjs`：本機預覽伺服器
- `PROJECT_BRIEF.md`：功能、資料結構及重要限制
- `AGENTS.md`：俾 Codex 讀取嘅專案工作指引
- `docs/DEPLOY.md`：重新部署方法

## 最快使用方法

1. 解壓縮 ZIP。
2. 在 Codex 選擇「開啟資料夾」，選擇 `swim-class-balance-codex`。
3. 對 Codex 講：

   > 請先閱讀 README.md、PROJECT_BRIEF.md 同 AGENTS.md，然後幫我預覽及檢查呢個 Web App。暫時唔好改功能。

4. 要修改時，清楚講出想改嘅功能，例如：

   > 請喺現有泳堂管家加入 WhatsApp 提醒按鈕，保留其他功能同本機資料格式；完成後跑測試同俾我預覽確認。

## 本機預覽

電腦已安裝 Node.js 的話，在專案資料夾執行：

```powershell
npm run preview
```

然後開啟 `http://127.0.0.1:4173`。

## 測試

```powershell
npm test
```

## 課程批量匯入

在「課程設定」按「匯入／更新課程」，可下載已填入 52 組 Google 課程表資料的 CSV 範本（Excel 可開啟），或直接選用內附參考資料。亦可上載相同五欄的 CSV／XLSX：課程名稱、年齡組別、課程人數、課堂時間（分鐘）、原價（HK$，每位學生）。匯入前會預覽新增、更新及未變更筆數；相同「名稱＋年齡＋人數」只更新課堂時間和原價，不會刪除其他課程。參考資料只供預覽，確認匯入前不會寫入瀏覽器資料。

## 泳班地點批量匯入

「泳班地點」內附 Google 表格的 17 組初始泳池／地點資料。頂部「匯入」可下載五欄 CSV 範本，或上載同欄位的 CSV／XLSX：課堂泳池、泳池地點、集合位置、泳池清潔日、年度維修時間。匯入前會顯示新增、更新、未變更筆數；相同「課堂泳池＋泳池地點」只更新後三欄，未列出的組合不會刪除。新增、編輯及刪除均以單一組合為單位，舊有學生及課堂儲存格式不變。

## 新增學生資料

個人資訊的「新增學生」表單可加入相片、年齡組別、選填出生月份及年份、性別、WhatsApp、地點及最多四組報讀課程。未成年學生選擇出生月份及年份後，表單會按今日日期顯示學生年齡；舊有出生日期資料仍會帶入月份及年份。課程名稱、人數與原價讀取課程設定；課堂地點讀取泳班地點清單。待確認學員暫無編號，並可在「待確認學員」篩選中跟進。儲存為已付款時，系統按 4 月 1 日起計的年度及成年／未成年類別編配 `A`／`K` 編號；已使用的序號不會因刪除學生而重用。舊學生資料保持原有堂數和排程，補齊新欄位後才會於編輯儲存時補編號。相片同樣儲存在本機瀏覽器；第一組報讀課程的首堂日期會作為現有時間表的下一堂日期，其餘課程資料保留在學生檔案。

## 重要私隱提示

目前版本將學生、課堂及付款資料儲存在使用者自己瀏覽器的 `localStorage`，不會自動同步到雲端。請勿輸入身份證號碼、健康紀錄、密碼或其他敏感資料。更換裝置或清除瀏覽資料前，應先在 App「設定」匯出 JSON 備份。

## 重新部署

分享包刻意不包含原作者的 Git 歷史、Sites 專案 ID、登入資料或部署憑證。朋友應使用自己嘅 GitHub 或 Sites 帳戶建立新專案。詳情見 `docs/DEPLOY.md`。
